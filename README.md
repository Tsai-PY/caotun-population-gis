# 南投縣草屯鎮各村里人口年齡分布 GIS 查詢系統

以地理資訊系統（GIS）地圖為互動查詢平台的南投縣草屯鎮各村里人口年齡分布查詢系統。

🔗 **線上系統網址**：https://tsai-py.github.io/caotun-population-gis/

---

## 🌟 核心功能

1. **互動式 GIS 村里邊界地圖**
   - 完整收錄草屯鎮 27 個村里之向量地理疆界（GeoJSON）。
   - 點選任一村里，邊界立即金黃色加粗高亮，地圖平滑自動聚焦放大至該里範圍。
   - 提供 6 種主題統計色階圖（Choropleth Map）：
     - 總人口數分級圖
     - 65歲以上高齡人口比例 (%) 色階
     - 0~14歲幼年人口比例 (%) 色階
     - 15~64歲青壯年人口比例 (%) 色階
     - 老化指數（老年/幼年 × 100）色階
     - 性別比（男/女 × 100）色階
   - 支援切換三種底圖（OpenStreetMap 標準圖、CartoDB 淺色圖、CartoDB 深色圖）。
   - 支援村里名稱與人口標籤一鍵開關。

2. **每差 5 歲年齡層統計明細表**
   - 完整涵蓋 `0~4歲`、`5~9歲`、`10~14歲` ... 直至 `95~99歲`、`100歲以上` 共 21 個 5 歲年齡區間與總計。
   - 包含合計人數、佔比、男性人數及比率、女性人數及比率、性別比、直觀視覺長條。
   - **單歲細項展開**：點擊任一 5 歲列即可展開該組內的單歲（例如 0歲、1歲、2歲、3歲、4歲）個別精確統計數字，並支援「全部展開 / 全部折疊」。

3. **人口結構與視覺化儀表板**
   - **人口年齡金字塔**：雙向水平長條圖直觀比對男女年齡結構。
   - **三階段年齡結構**：幼年（0~14歲）、青壯年（15~64歲）、高齡（65歲以上）比例進度條。
   - **核心指標卡**：總人口、男女比、性別比、老化指數、扶養比、扶老比、扶幼比。
   - **報表匯出**：支援一鍵匯出當前里年齡資料為 CSV 報表，或一鍵複製表格文字至剪貼簿。
